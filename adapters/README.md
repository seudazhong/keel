# IM gateway adapters

Pluggable IM adapters normalise each platform to one event + message-chain type
(FR-S3). Each adapter becomes its own workspace package here.

- **onebot/** (QQ) and **telegram/** — M1 (WS-E)
- **wecom/**, discord/, slack/ — M2

Empty in M0; the OneBot(QQ) adapter is the first, in M1.
