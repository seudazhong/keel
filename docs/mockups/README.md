# Historical product mockups

The HTML files in this directory are product/UX exploration snapshots. They do not represent
the current React UI, supported routes, responsive behavior, accessibility, or committed
release scope.

Use [`../PRD.md`](../PRD.md) for the target product,
[`../STATUS.md`](../STATUS.md) for implemented surfaces, and the live React source in
[`../../web/`](../../web/) for current behavior. Keeping this single index current avoids
adding banners to every standalone mockup.
