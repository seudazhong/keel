自托管的「连接式 AI 助理」平台

Keel 把同一个 scoped agent（人格 + 记忆 + 工具集 + 连接器 + 权限边界）投射到 Web 与 IM 两个界面。产品重心是连接器（邮件/日历/文档）+ 记忆 + 检索 + 消息， 而非代码执行。以下是产品主要屏幕的效果图，用于在继续开发前对齐体验方向、暴露设计隐患。

◆
这些屏幕里用 黄色虚线框 标注了它们暴露出来的 待定设计决策 / 隐患——这正是做效果图的目的：把问题提前显性化。汇总见 UX 设计文档。
